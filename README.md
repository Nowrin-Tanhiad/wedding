# Lalon & Saria – Fairy Tale Wedding Album
Static site: no build step needed.
## Deploy on GitHub Pages
1. Create a new GitHub repository and upload ALL files (index.html, the assets folder, .nojekyll) to the ROOT of the repo.
2. Repo Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
3. After a minute open https://YOUR-USERNAME.github.io/YOUR-REPO/
The main file must be named exactly `index.html` (lowercase) and the `assets` folder must stay next to it.
